# Lumos Launcher

Official Windows installers and signed update manifests for Lumos Project SRP.

## Current test release

[Download Lumos Launcher 0.7.2](https://github.com/tanva-studio/lumos-launcher-releases/releases/tag/v0.7.2)

Close the game and exit Lumos Launcher from the system tray before installing. A Localhost shortcut is included.

Version 0.7.2 follows the server password requirement when joining and adds offline Fast (Whisper Base) / Accuracy (Whisper Small) modes in Settings. Accuracy remains the default; Fast can make more Thai transcription mistakes. This is a prerelease for manual testing and is not offered by the stable automatic update feed.
