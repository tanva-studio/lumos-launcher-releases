# Lumos Launcher

Official Windows installers and signed update manifests for Lumos Project SRP.

Powered by ArcaneMP and MafiaHub. The official ArcaneMP runtime is included; players must own and install Hogwarts Legacy separately.

Download installers from this repository’s Releases page. Launcher update manifests are signed with a separate Ed25519 release key.

This repository contains release artifacts only. Server source code, server TLS private keys and the update signing private key are not published here.
